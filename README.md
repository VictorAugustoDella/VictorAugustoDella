### 🏆 Strongest project

**[Price Tracker](https://github.com/VictorAugustoDella/Price-tracker-API)**  

A full-stack price monitoring application built with **Flask**, **React**, **PostgreSQL**, **Playwright**, **Celery**, **Redis**, **Docker** and **GitHub Actions**.

The application allows users to register product URLs, automatically scrape product prices, store price history, calculate statistics and run scheduled background checks to detect price changes over time.

This project showcases:

- REST API development with Flask
- secure authentication using JWT in HTTP-only cookies
- CSRF protection for cookie-based authentication
- relational data modeling with SQLAlchemy and PostgreSQL
- web scraping with Playwright
- background jobs with Celery and Redis
- periodic scheduling with Celery Beat
- automated tests with Pytest
- Dockerized full-stack environment
- CI pipeline with GitHub Actions
- React frontend with protected routes, dashboard and product details pages
